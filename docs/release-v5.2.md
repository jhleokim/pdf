# PDF Studio v5.2.0

기존 브라우저·단일 HTML 구조에 맞춰 작성한 개선입니다. Stirling PDF 코드나 서버 엔진을 복사하지 않았으며 신규 서비스·라이브러리를 추가하지 않았습니다. 운영 사이트 배포 기록은 아닙니다.

## 변경

1. **혼합 PDF OCR**: 디지털 머리말·페이지 번호가 있다는 이유로 스캔 본문을 건너뛰지 않습니다. 이미지가 함께 있는 페이지는 기존 텍스트 영역을 인식 입력에서 제외하고 나머지를 읽습니다. 텍스트만 있는 페이지는 기존 검색 텍스트를 유지합니다. 미리보기가 주석 배열을 초기화할 때 OCR 결과가 오래된 것으로 판정되던 캐시 키도 수정했습니다.
2. **Pro 개인정보 마스킹**: 영역 그리기·이동·모서리 크기 조절·삭제·페이지 이동을 지원합니다. 저장·인쇄에는 입력 양식의 표시까지 먼저 이미지로 합친 뒤 마스크를 적용하고, 모든 페이지를 새 이미지 PDF에 다시 그립니다. 원본 PDF 객체·숨은 텍스트·첨부파일·원본 메타데이터를 복사하지 않습니다. 원본 파일은 유지됩니다. 이 방식은 전체 문서의 검색·복사·링크·양식을 없애므로 저장 전에 확인합니다. 기본 200dpi PNG이며 페이지당 12MP, 한 변 12,000px 제한으로 큰 페이지는 해상도가 낮아질 수 있습니다. 일반 사각형 주석은 개인정보 삭제 기능이 아닙니다.
3. **압축 진단과 중복 제거**: 원본 이미지 중 현재 엔진이 처리 가능한 범위를 표시하고, 바이트와 PDF 이미지 사전이 동일한 중복 이미지를 하나로 공유합니다. 1비트 CCITT/JBIG2 등 모든 이미지 형식을 새로 지원하는 것은 아닙니다. 처리 가능 표시는 예상 절감률이 아니며, 이미 압축된 문서는 절감이 작을 수 있습니다. 마스킹 출력은 용량이 커져도 원본으로 되돌리지 않습니다.
4. **썸네일 메모리**: 화면 주변 페이지만 순차 생성하고, 표시 폭에 맞춘 해상도로 보관합니다. 화면 밖 이미지는 LRU 24개 기준으로 해제하며 현재 보이는 페이지는 예외입니다. 다시 보이면 재생성합니다. 문서 객체·편집 이력·최종 PDF까지 고정 메모리라는 뜻은 아닙니다.
5. **문서 구조 보존**: 한 원본의 모든 페이지를 재정렬할 때 원래 페이지 객체·양식·북마크를 유지합니다. 전자서명이 있거나 삭제·병합에서 양식·북마크 손실 가능성이 있으면 저장 전에 안내합니다. 서명을 암호학적으로 검증하거나 여러 문서의 양식·북마크를 완전 병합하는 기능은 아닙니다.
6. **도움말 정리**: 반복 설명은 옅은 회색 `?`에 묶어 PC 호버·키보드 포커스·모바일 길게 누르기로 표시합니다. 오류·진행 상태·문서 전송 동의·손실 확인은 화면에 남습니다.
7. **모델 순서**: Paddle OCR 기본, Tesseract 두 번째, 웹 Google Vision 세 번째. 8회 클릭·활성화 암호 창은 빌드에서 제거했습니다. Vision은 매 실행 전 전송 동의를 받으며 단독 HTML에는 포함하지 않습니다.
8. **버튼 정리**: OCR은 인식 범위 선택과 실행 버튼 하나로 통합했습니다. 데스크톱의 중복 결과 다운로드·미리보기 버튼은 헤더 동작으로 통합하고 모바일에 필요한 동작은 유지합니다.

## 검증

- `npm test`: 기존 회귀 테스트와 OCR 정책·문서 구조 검사·이미지 중복 제거/진단 테스트.
- `node tests/create-v52.cjs`: 웹 통합 fixture. 실제 PDF 저장 후 텍스트 추출·재렌더링으로 마스킹을 확인합니다. 입력 양식이 마스크를 덮지 않는지, 90/180/270도 회전·CropBox·UserUnit에서 위치가 일치하는지, Pro 저장 확인·취소·결과·82페이지 썸네일을 검증합니다.
- `node tests/create-v52-mobile.cjs`: 390×844 iframe으로 실제 모바일 CSS 배치와 마스킹 편집창·빈 페이지 버튼을 확인합니다. 별도 모바일 기기의 성능 측정은 아닙니다.
- `tests/v52-ocr-browser.js`: 두 엔진을 실제 실행해 이미지 안의 `123456`, `987654`를 읽고 디지털 머리말이 중복되지 않는지 검사합니다. 배포 자산을 제공하는 localhost에서 실행하며 외부 문서 전송은 없습니다. 이 짧은 견본의 성공이 모든 계약서의 정확도를 보장하지는 않습니다.
- Basic↔Pro 12개, 전체 미리보기 10개, 편집 이력 18개 시나리오를 재실행했습니다.

단독 HTML은 두 로컬 엔진·모델을 내장하고 클라우드 모듈이 빠졌는지 빌드 테스트로 검사합니다. 이번 환경의 브라우저 URL 보안 정책이 `file://` 직접 탐색을 차단하여 파일 직접 실행의 자동 검증은 완료하지 못했습니다. Google Vision 실제 과금 API 호출도 이번 검증에 포함하지 않았습니다.
