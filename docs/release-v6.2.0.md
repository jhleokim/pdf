# v6.2.0 · 테마와 검토 스탬프

## 변경

- 기존 Light/Dark 버튼을 **화면 설정** 창으로 변경했습니다. Studio는 하나색과 기존 화면을 유지하며, Paper는 따뜻한 중성색의 배경과 절제한 그림자를 사용합니다. 각 테마에서 Light, Dark, 시스템 밝기를 고를 수 있습니다. 초기 설정은 Studio/Light이며 기존에 저장한 밝기 설정을 유지합니다.
- 화면 설정은 키보드로 선택하고 Esc·닫기 버튼·바깥 클릭으로 닫습니다. 포커스는 설정 버튼으로 돌아옵니다. 작은 화면에서는 아래쪽에 표시하고 밝기/닫기 버튼은 44px 이상입니다.
- 테마는 CSS 변수와 로컬 화면 설정만 변경합니다. PDF 캔버스, 편집 기록, OCR, 네트워크를 호출하지 않습니다. 이전 밝기 전환의 `showPreview` 호출을 제거했습니다.
- 검토 스탬프 16개를 짧은 문구로 정리했습니다. ‘수정해주세요’ → ‘수정’, ‘출처를 확인해주세요’ → ‘출처 확인’ 등입니다. 자주 쓰는 8개를 먼저 보여주고 나머지는 ‘문구 더 보기’에서 선택합니다.
- 구름·타원·이중 테두리·장식과 꼬인 화살표를 얇은 사각 테두리와 직선 화살표로 통일했습니다. 기본 빨강, 사용자 지정 색상/문구, 여러 개 배치, 크기 조절, 화살표 끝점 이동, PNG/PDF 출력은 유지합니다.

## 검증

- `npm test`: 327개 통과, 실패/건너뜀 0개. 회전된 CropBox와 UserUnit 1/2에서 화살표 PDF 렌더링과 원본 검색 텍스트 유지 검사 포함.
- 브라우저 테마 검사: Basic/Pro 각각 2개 테마 × 3개 밝기 조합. 문서 픽셀·페이지 선택·편집 상태 유지, 미리보기 재렌더링 0회, 설정 창 화면 내 배치와 포커스 복귀 확인.
- 단일 HTML 빌드도 네트워크 연결을 CSP로 막은 로컬 테스트에서 같은 검사를 수행. 390×844 iframe으로 모바일 배치와 44px 조작 영역 확인. 이 검사는 실제 휴대폰 또는 `file://` 실행 검증을 대신하지 않습니다.
- 스탬프 흐름 8개 검사: 페이지 간 이동, 여러 개 배치, 비례 크기 조절, Enter/Esc, 지정 페이지 저장, 기존 스탬프 편집, Pro/Basic 연계, 실패 복구와 실행 취소/다시 실행.
- 이전 스탬프 검사에서 썸네일 실패를 주입하던 부분은 현재 지연 썸네일 구조에 맞게 전환 준비 단계의 실패 주입으로 변경했습니다.
- 브라우저에서 Esc 닫기와 포커스 복귀를 직접 조작했습니다.
