# v6.4.7 — 다섯 관점의 유지보수 합동 점검

점검일: 2026-09-19. 편집·이력, 개인정보, 출력 결과, UI·접근성, 배포·단독 실행 호환성으로 나누어 검토했다. 병렬 검토 후 변경 내용을 교차 검토하고 재현 테스트와 통합 테스트를 수행했다. 공인 보안·접근성 인증이나 모든 PDF에 대한 호환성 보장은 아니다.

## 검증 방식

합성 PDF와 모의 장애를 사용했다. 실제 회사 문서나 API 키를 출력하거나 외부 OCR에 전송하지 않았다. 복제본 격리는 저장된 PDF를 다시 열어 텍스트를 추출했고, 레이어 결함은 실제 MuPDF가 읽는 숨김 텍스트로 재현했다. UI 경쟁 조건은 완료 순서를 바꾼 비동기 작업으로 검사했다. 서버의 동의·출처·요청 크기·응답 검증·취소·비밀정보 관련 테스트는 모의 요청이다.

```sh
node scripts/build.mjs
node --test --test-concurrency=1 tests/*.test.cjs
node scripts/build-standalone.mjs
node scripts/build-deploy.mjs
node tests/create-maintenance-ui.cjs
python tests/serve-local.py
```

최종 소스의 전체 자동 테스트 **446개 통과, 실패·생략 0개**. 이후 실제 인쇄 취소 회귀 테스트 1개를 추가 실행해 통과하여 총 **447개**를 확인했다. 새로 추가한 회귀 테스트는 30개다. 빌드 전 검사에서 발생한 생성 파일/소스 불일치는 최종 웹·단독 HTML 재생성 후 전체 검사를 다시 실행해 해소했다.

브라우저 검사 결과:

- 도움말·키보드 처리: 기존 빌드에서는 6개 중 3개 실패, 수정 후 데스크톱/390px 각각 **6/6 통과**. 실제 저장 창에서 키보드로 도움말을 열어 가림 없이 표시되는 것도 확인했다.
- 검토 스탬프 **8개**, 모바일 크기 텍스트·저장 **9개**, 되돌리기 **18개**, 모바일 크기 선택 저장 **9개** 통과.
- 단독 HTML의 Basic/Pro 연동 **12개**, 개인정보 마스킹·흑백 미리보기/저장·검색 텍스트 보존·엔진 취소/재시작 **34개** 통과. 후자는 HTML 로드 이후 HTTP 요청이 없음을 확인했다.
- 인쇄 흐름은 데스크톱/390px 각각 **13개** 통과. 브라우저 PDF 뷰어의 준비 완료·프린트 호출만 모의 처리하고 실제 출력 PDF의 내용·페이지 크기를 검사했다. 처음 발견된 취소 실패는 테스트가 비동기 모드 전환을 기다리지 않아 전환 작업을 취소한 문제였다. 전환 완료 후 인쇄 자체를 취소하도록 검사 코드를 수정했으며 제품 인쇄 코드는 변경하지 않았다. 실제 종이를 출력한 검사는 아니다.
- 최신 빌드에서 합성 텍스트 **1,000페이지(0.21MiB)** 불러오기 3.92초, 선택 3페이지 저장 1.25초, 전체 Basic 저장 17.79초로 완료했다. 썸네일 캔버스는 22개였다. 전체 회전+되돌리기 중 메인 스레드 지연 약 1.56초는 여전히 남는다. 한 번의 실행 값이며 성능 보장 수치가 아니다. 직전 버전의 90.49MiB/212페이지 스캔 측정은 [별도 기록](release-v6.4.6.md)에 있으며 이번에 같은 스캔 벤치마크를 재실행한 것은 아니다.

## 제약과 후속 과제

- 숨김 레이어가 있는 PDF의 일부 저장·병합·복제 및 해당 재구성 경로의 미리보기/OCR은 표시 상태 보존을 보장하지 못해 중단한다. 원본 프로그램에서 필요한 레이어만 포함한 PDF로 다시 저장해야 한다. 원본 불러오기·Basic 썸네일과 카탈로그를 유지하는 단일 원본 전체 저장은 별도 경로다. 개인정보 마스킹은 레이어 문서를 보수적으로 거부한다. 전체 이미지 변환으로 우회하지 않는다.
- 복제본을 분리하면 반복 페이지의 내부 자원이 추가되어 파일이 커질 수 있다. 잘못된 주석 전파를 막기 위한 선택이며 일반적인 서로 다른 페이지 복사는 기존 일괄 경로를 유지한다.
- 대용량 문서의 전체 메모리 저장, 1,000페이지 일괄 편집 지연, Google Vision 조직 동시 호출 제한과 작업 복원 부재는 [v6.4.6 점검의 한계](release-v6.4.6.md)가 계속 적용된다. 이번 점검만으로 200명 동시 사용이나 무중단을 보장하지 않는다.
- 물리 모바일 기기, 실제 프린터 출력, Acrobat의 모든 기능, 실제 Google API의 장시간 연속 처리, 기업 보안 정책별 직접 `file://` 실행은 이번 검증 범위 밖이다. 단독 HTML 검사는 로컬 HTTP에서 외부 연결을 차단하여 내장 자산 경로를 검사한다.
