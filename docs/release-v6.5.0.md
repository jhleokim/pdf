# v6.5.0 — OCR 기반 개인정보 자동 탐지

## 사용 흐름

1. Pro → 개인정보 마스킹 → 자동 탐지에서 현재·선택·전체 페이지를 선택한다.
2. 현재 문서 배치와 일치하는 전체 OCR 결과가 없으면 `OCR로 이동`으로 이동한다. `페이지 전체 인식 · 개인정보 탐지용`을 선택하여 기존 Paddle/Tesseract/웹 Vision 인식을 실행한다. 디지털 PDF의 검색 텍스트가 있어도 이 모드에서는 재인식한다.
3. 번호 중심·연락처 포함 프리셋 또는 원하는 종류를 직접 선택한다. 종류는 주민·외국인등록번호, 계좌번호, 카드번호, 전화번호, 이메일, 이름, 주소다. 전체 가리기와 일부 남기기를 비교할 수 있다.
4. 원본 위 후보와 목록을 연결해 확인한다. 잘못 탐지한 항목은 제외하고, 영역이나 모서리를 끌어 경계를 수정한다. 영역 선택 후 방향키는 위치를 미세 조절한다. 후보가 있는 각 페이지에서 확인 체크를 해야 적용된다.
5. 적용하면 기존 부분 삭제 엔진에 마스킹 영역을 전달한다. 원본 파일은 유지하고 PDF 저장 때 가린 내용을 제거한다. 실행 취소·다시 실행은 마스킹과 OCR 정리를 함께 처리한다.
6. 유용했던 종류와 가리기 방식을 이름 붙여 프리셋으로 저장한다. 최대 8개이며 같은 이름으로 저장하면 갱신한다. 후보·문서 본문은 프리셋에 저장하지 않는다. 자동 추천·사용 이력 수집은 없다.

## 탐지 및 좌표

추가 모델 없이 OCR 결과에서 숫자 형식, 생년월일, 카드 검증 숫자와 주변 라벨을 조합한다. 계좌·이름·주소는 라벨 문맥을 요구해 일반 숫자·상호·문장을 무작정 가리지 않는다. 서로 떨어진 표 열이나 다른 줄의 숫자는 이어붙이지 않는다. OCR 교정에서 지운 원문은 다시 탐지하지 않는다.

부분 가리기 규칙은 주민·외국인등록번호 뒤 7자리, 전화 가운데 번호, 계좌 끝 4자리 유지, 카드 처음·끝 4자리 유지, 이메일 아이디 일부, 이름 가운데, 주소 상세 부분이다. 조직의 확정 마스킹 규정이라고 주장하지 않는다. 실제 문서와 사내 요구에 따라 종류·전체/부분 방식을 선택하고 검토한다.

Paddle의 글줄 단위 위치와 부분 단어 위치는 글자 폭을 이용한 추정이다. 다른 글꼴·자간·기울기에서는 어긋날 수 있어 `위치 추정`으로 표시한다. 자동 탐지가 개인정보 부재나 완전 삭제 범위의 적절성을 보증하지 않는다. 누락된 항목은 직접 지정한다. 특히 OCR이 잘못 읽거나 손글씨·라벨 없는 이름·주소·비정형 계좌는 놓칠 수 있다.

기울기·재단·페이지 규격 변환이 켜져 있으면 변환 후 OCR 좌표를 원본에 잘못 적용하지 않도록 탐지를 중단한다. 원본 배치에서 인식하고 가린 뒤 보정한다. 마스킹 후 90도 페이지 회전에서는 가릴 영역도 함께 회전한다. 레이어 PDF 마스킹 등 기존 엔진의 지원 제한은 유지한다.

## 검색 텍스트와 원문 보존

페이지 전체를 이미지로 바꾸지 않고 기존 MuPDF 부분 삭제 경로를 사용한다. 남은 원본 글자와 벡터를 유지한다. 전체 OCR에서 원래 검색 텍스트의 영역을 기록하여 OCR 글자가 중복 삽입되지 않게 한다. 위치를 확인할 수 없는 원래 텍스트는 안전상 OCR 추가를 허용하지 않는다.

마스킹과 겹치거나 경계에 닿는 OCR 단어/글줄은 검색층에서 통째로 제외한다. 글줄 안의 일부 번호만 가린 경우 같은 글줄의 안전한 OCR 텍스트도 검색되지 않을 수 있다. 이는 민감한 원문이 검색·복사로 남는 것을 막기 위한 선택이며, 가리지 않은 글자의 시각적 모습은 유지된다. 기존 디지털 PDF 글자의 검색은 부분 삭제 결과를 따른다. 정리한 OCR 결과에는 원래 표·교정·응답 payload를 남기지 않는다.

검토 중 문서나 OCR 결과가 바뀌면 적용을 중단한다. 완료 결과 캐시도 새 마스킹 상태와 함께 갱신한다. OCR 결과를 PDF에 포함하는 기존 확인 절차는 유지한다. 마스킹 적용 자체가 OCR 인식 품질에 대한 사용자 동의를 대신하지 않는다.

## 자원 사용

페이지 단위로 탐지하고 사이마다 브라우저에 제어권을 돌려준다. 원본 미리보기는 한 장만 유지하고 후보 목록은 50개씩 표시한다. 탐지는 페이지당 50,000 OCR 영역·500,000자·2,000 후보, 문서당 10,000 후보 한도를 넘으면 범위를 나누도록 명시적으로 중단한다. 한도를 넘은 일부 결과만 조용히 적용하지 않는다. 이 한도는 문서 자체의 최대 페이지 수가 아니다.

합성 데이터 단일 로컬 측정에서 20,000단어 탐지는 약 92ms, 20,000단어와 200마스크의 검색층 정리는 약 16ms였다. OCR 실행·모델 준비·원본 렌더링·PDF 저장 시간은 포함하지 않는다. 기기별 성능 보장 수치가 아니다.

## 검증

탐지·교정·좌표·프리셋·검색층 정리, 전체 OCR 및 기존 native 텍스트 중복 방지, Vision 전송 동의 범위, 페이지 회전의 실제 부분 삭제를 자동 검사한다. 브라우저에서는 실제 로컬 Paddle OCR로 합성 스캔/디지털 PDF 2쪽을 인식한 뒤 주민번호·전화·이메일·카드 후보 생성, 페이지별 확인, 적용 및 실행 취소를 확인했다. 실제 개인정보 문서는 테스트나 외부 서비스에 전송하지 않았다.
