# v6.2.1 · Pro 기본값과 도움말

- 처음 Pro에 진입했을 때 자동 기울기 보정과 용량 최적화가 켜지지 않도록 변경했습니다. 흑백 변환·대비·배경 보정·여백 재단 등도 원본 상태로 시작합니다. 설정 초기화도 같은 기본값을 사용합니다. 사용자가 직접 설정한 작업을 단순히 Pro 버튼을 누를 때마다 지우지는 않습니다.
- 텍스트 인식을 용량 최적화 다음, Pro 도구의 마지막으로 옮겼습니다. 웹과 단독 HTML에 동일하게 반영하며 기존 OCR 모델 선택과 실행 방식은 유지합니다.
- 물음표 도움말은 마우스를 1초 올려두어야 표시합니다. 떠나거나 스크롤하면 대기와 표시를 취소하고, 마우스로 클릭해 포커스를 옮겨도 대기를 건너뛰지 않습니다. 키보드 포커스에서는 바로 읽을 수 있고 Esc로 닫습니다. 모바일 길게 누르기와 손을 떼거나 움직였을 때 닫기도 유지합니다.
- [Stirling과 용량 최적화 비교](compression-comparison-v6.2.1.md)를 추가했습니다. 이번 변경에는 압축 알고리즘 교체나 동일 파일 압축 벤치마크가 포함되지 않습니다.

## 검증

- `npm test`: 327개 통과, 실패·건너뜀 0개.
- 웹과 단일 HTML의 브라우저 검사 각각 7개: 처음 시작·Basic/Pro 왕복 시 원본 및 기본값 유지, 설정 초기화, OCR 순서와 중복 ID, 1초 도움말, 빠른 통과 취소, 마우스/키보드 포커스 구분, 터치 유지·해제·이동.
- 단일 HTML은 390×844 iframe에서 네트워크 요청을 CSP로 막고 실행했습니다. 실제 휴대폰이나 `file://` 직접 실행을 검증한 것은 아닙니다.
- 테스트 문서는 로컬에서 생성한 합성 PDF이며 사용자 문서를 업로드하지 않습니다.

```sh
npm run build
npm run build:standalone
npm test
node tests/create-pro-defaults.cjs
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `tests/fixtures/pro-defaults.html`과 `tests/fixtures/pro-defaults-mobile.html`의 PASS 결과를 확인합니다. 생성된 테스트 HTML은 Git에 포함하지 않습니다.
