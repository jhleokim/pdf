# PDF Studio v5.2.1 — 마스킹 후 검색 텍스트 보존

v5.2.0은 개인정보 마스킹의 마지막 저장 단계에서 확인한 OCR 결과까지 제거했습니다. 마스킹 후 텍스트 인식을 실행해도 검색할 수 없던 오류를 수정했습니다.

- 가린 페이지의 원본 PDF 텍스트는 복사하지 않습니다. 마스킹한 화면에서 인식하고 사용자가 포함을 확인한 OCR만 새 검색 텍스트로 기록합니다. 마스킹·페이지·보정 설정이 달라지면 기존 결과와 인식 캐시를 사용하지 않습니다.
- 원래 디지털 텍스트가 있던 페이지도 마스킹하면 재인식합니다. 기존 검색 텍스트가 있다는 이유로 건너뛰거나 남은 글자를 인식 입력에서 제외하지 않습니다.
- 가리지 않은 페이지는 출력 PDF의 텍스트를 새 Unicode 검색 텍스트로 옮깁니다. 회전·CropBox·UserUnit을 반영해 기준선과 방향을 보존합니다. 원본 PDF 객체·첨부파일·메타데이터는 복사하지 않습니다.
- 한글 교정 결과와 Pro → Basic 전환에도 같은 검색 텍스트를 유지합니다. 기존 저장 확인과 결과 보고를 실제 동작에 맞췄습니다.

## 사용

**Pro → 개인정보 마스킹 → 텍스트 인식 → 확인한 결과를 PDF에 포함 → 저장**.

OCR을 확인하지 않은 마스킹 페이지는 이미지로 남습니다. 일반 주석 사각형은 개인정보 영구 삭제 기능이 아닙니다. 링크·양식은 일반 페이지로 저장하고 첨부파일을 제거합니다. 새 엔진·서버·외부 통신은 추가하지 않았습니다.

## 검증

- `npm test`: 317개 통과.
- `node tests/create-privacy-search.cjs`: 로컬 웹에서 실제 PP-OCRv5와 Tesseract 인식 후 Pro 저장 파일을 다시 열어 공개 숫자 검색, 가린 계좌번호 미추출, 검색 텍스트 중복 없음, 한글·영문 기존 텍스트 보존, 검은 마스킹 픽셀, 첨부파일·양식·메타데이터 제거를 확인했습니다. 오래된 결과 거부, 한글 교정, Basic 전환도 검사합니다.
- `node tests/create-v52.cjs`: 개인정보 제거·입력 양식·회전·CropBox·UserUnit·저장 확인/취소·썸네일 회귀 검증.
- 단독 HTML은 로컬 웹에서 내장 모델로 같은 OCR·저장 검증을 실행합니다. 이 환경은 `file://` 직접 탐색을 차단하므로 파일 직접 실행까지 검증했다는 의미는 아닙니다. Google Vision의 실제 과금 API 호출은 하지 않았으며 동일한 공통 OCR 저장 경로를 사용합니다.
