# v6.4.5 페이지 작업 메뉴

페이지 썸네일을 우클릭하거나 하단 `⋯` 버튼을 누르면 해당 위치에 작업 메뉴를 제공합니다. 기존 선택에 포함된 페이지에서는 여러 페이지 선택을 유지하고, 선택하지 않은 페이지에서는 해당 페이지만 선택합니다. Basic 그리드와 Pro 목록에서 같은 동작을 사용합니다.

- 크게 보기, 좌우 회전, 복제, 순서 변경, 앞/뒤 빈 페이지, 선택 페이지 저장, 삭제.
- 복제·회전·삭제·삽입은 기존 실행 취소/다시 실행과 연결합니다.
- 선택 저장은 선택한 페이지만 준비하며 전체 문서 결과를 먼저 만들지 않습니다.
- 키보드 Shift+F10, 메뉴 키, 위/아래/Home/End, Escape 지원. 메뉴 바깥 클릭·스크롤·창 크기 변경 시 닫힙니다.
- 모바일 `⋯` 버튼과 메뉴 항목은 44px 터치 영역을 사용합니다. 기존 길게 눌러 페이지 순서 바꾸기는 유지합니다.
- 기존 테마 색상을 따르는 얇은 테두리와 그림자, 짧은 등장 효과를 사용하며 동작 줄이기 설정을 존중합니다.

## 데이터 및 성능

메뉴는 하나만 만들고 이벤트 위임으로 동작합니다. 열 때 PDF/OCR 작업을 새로 실행하지 않습니다. 복제 시 원본 PDF 데이터는 재사용하고 주석 메타데이터만 분리합니다. 썸네일 캔버스는 공유하지 않고 기존 24개 LRU 캐시로 필요할 때 생성합니다.

복제한 페이지의 OCR 식별자와 도장 대상, 기울기 설정을 연결하며 실행 취소 시 복제로 추가된 OCR만 제거합니다. 검색 텍스트를 유지하는 기존 PDF 저장 경로를 사용합니다. 새 서비스·외부 통신을 추가하지 않습니다.

## 검증

- 자동 테스트 366개 통과(직렬 실행).
- 데스크톱과 390×844 모바일 프레임 각각 페이지 메뉴 14개 검증 통과: 다중 선택, 화면 경계, 키보드, 터치 영역, 회전/삭제/삽입/복제와 undo/redo, Pro OCR·도장 보존, 검색 가능한 선택 저장, 처리 중 차단, 외부 요청 없음.
- 실제 브라우저 우클릭과 메뉴에서 복제 실행 확인.
- 기존 선택 저장 브라우저 회귀 검증 포함.
- 단독 HTML 재생성과 내장 스크립트 구문·버전·중복 ID·외부 실행 의존성 검증 포함. 이 환경의 브라우저 도구가 file:// 접근을 제한하므로 단독 HTML 직접 실행 검증은 하지 못했습니다.

실제 Android/iOS 장치에서의 터치 검증은 별도이며 모바일 결과는 브라우저 내 390px 프레임 기준입니다.
