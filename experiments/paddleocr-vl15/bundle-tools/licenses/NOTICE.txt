Experiment modifications
  The original Paddle image preprocessing, prompt construction, M-RoPE, and
  Spotting output handling were ported to JavaScript in preprocess.mjs.
  Source URLs and assumptions are recorded in that file. The browser resize
  implementation is not claimed to be byte-identical to Pillow.
  paddle-session.mjs adds browser inference orchestration and adapts results
  to PDF Studio. Experimental UI overrides replace the local Tesseract OCR
  provider while retaining the existing searchable-PDF writer.
  Standalone packaging replaces developer HTTP asset loading with embedded
  Base64 chunks, cached Uint8Array data, and local Blob runtime URLs.
  These modified browser files and packaging adapters are experimental work;
  they do not represent upstream model/runtime endorsement.

Existing PDF Studio notices
  Original PDF Studio PDF/rendering/markup font assets and notices remain in
  the generated application shell. Tesseract engine assets and their isolated
  OCR notice block are removed together in this Paddle-only experiment.
