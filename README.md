# PDF 페이지 편집기

브라우저 안에서만 동작하는 **완전 오프라인** PDF 페이지 편집기입니다.
`index.html` 한 파일이 전부이며, 열린 파일은 기기 밖으로 나가지 않습니다 (네트워크 요청 0건).

## 기능

| | |
|---|---|
| **페이지 편집** | 여러 PDF를 합쳐서 순서 변경 · 회전 · 삭제 |
| **사진 삽입** | JPG·PNG·WEBP·GIF 등을 새 페이지로 추가하거나, 페이지 위에 직접 붙이기 |
| **영역 강조** | 사각형 · 타원 · 클라우드 마크를 그려 저장 시 PDF에 벡터로 인쇄 |
| **모바일 지원** | 페이지/미리보기 전환, 길게 눌러 순서 변경, 핀치 확대, 하단 액션바 |
| **화면 테마** | 시스템 설정 · 밝게 · 어둡게 |

## 사용

GitHub Pages에 배포되어 있다면 주소를 열기만 하면 됩니다.
내려받아 `index.html`을 더블클릭해도 똑같이 동작합니다 — 서버도, 설치도 필요 없습니다.

### 단축키

| 키 | 동작 |
|---|---|
| `Shift` + 클릭 | 범위 선택 |
| `Ctrl` / `⌘` + 클릭 | 개별 선택 토글 |
| `Ctrl` / `⌘` + `A` | 전체 선택 |
| `Ctrl` / `⌘` + `S` | PDF로 저장 |
| `Ctrl` / `⌘` + 휠 | 보드 열 수 조절 / 미리보기 확대·축소 |
| `Del` | 선택 항목 삭제 |
| `Esc` | 그리기 도구 해제 |

## 포함 라이브러리

파일 하나로 동작하도록 아래 라이브러리를 본문에 인라인했습니다. 라이선스 전문은 `index.html` 하단에 있습니다.

- [pdf.js](https://mozilla.github.io/pdf.js/) 3.11.174 — Mozilla, Apache License 2.0
- [pdf-lib](https://pdf-lib.js.org/) 1.17.1 — Hopding, MIT License
- Foxit 표준폰트 / Liberation 폰트

## 디자인 노트 — "제도판"

설계 도면 세트와 인쇄 교정지의 시각 언어를 빌렸습니다.

- **색** — 종이 같은 중성 바탕, 강조색은 단 하나이며 상태 표현에만 쓴다. 파괴적 동작에만 적색. 그라디언트·글로우 없음
- **구조** — 그림자가 아니라 1px 헤어라인이 구조를 만든다. 그림자는 실제로 떠 있는 것에만
- **활자** — 11·12·13·15·19·24 여섯 단계. 수치는 전부 tabular-nums. 넓은 자간의 소문자 라벨은 도면 표제란의 관습
- **아이콘** — 이모지 없이 굵기 1.6의 stroke SVG 한 세트로 통일
- **모션** — 120–180ms, 상태가 바뀔 때만. 장식적 반복 애니메이션 없음
