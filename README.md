# PDF Studio — Basic & Pro

브라우저 안에서 동작하는 **오프라인 지원** PDF 페이지 편집기입니다.
`index.html` 한 파일이 전부이며, 문서 처리에 업로드나 외부 서비스 호출을 사용하지 않습니다.

웹에 올리는 파일과 standalone 파일은 동일한 `index.html`입니다. 실행할 때 서버·CDN·계정·API 키가 필요하지 않습니다. 개발용 `src/`, `scripts/`, `tests/` 폴더는 배포하거나 함께 배포할 필요가 없습니다.

## 작업 모드

**Basic**에는 기존 페이지 편집, 사진 삽입, 영역 강조 기능을 모두 유지했습니다. 상단 **Basic / Pro** 전환은 현재 문서·페이지 선택·편집 내용을 유지하고 작업 도구만 바꿉니다.

**Pro**는 오른쪽 설정 패널에서 다음 기능을 제공합니다. 모바일에서는 **편집 화면 / Pro 설정**으로 전환합니다.

- 용량 최적화: 품질 프리셋, 이미지 긴 변 1,600 / 2,400 / 3,200 px 제한, JPEG 품질 조절.
- 스캔 보정: 지원되는 이미지의 회색조 변환, 대비 강화, 흰 배경 기준 조절.
- 페이지 규격: 표시 방향 기준 mm 여백 재단, 비율을 유지한 A4 맞춤.
- 페이지 번호: 시작 번호, 앞부분 제외, 아래 가운데/오른쪽 배치.
- 워터마크: 한글을 포함한 문구를 문서 전체에 표시.
- 선택 페이지의 원본/결과 비교, 실제 용량 변화와 처리 보고, 별도 결과 다운로드, 처리 취소.

설정은 **결과 만들기**를 눌렀을 때 출력 사본에 적용됩니다. 상단 저장과 Ctrl/⌘+S는 Basic에서 편집본 저장, Pro에서 결과 만들기를 실행합니다. 원본 파일이나 편집 중인 문서를 덮어쓰지 않습니다. 결과 생성 후 편집이나 설정을 바꾸면 이전 결과는 닫힙니다.

## 기존 OCR 보존과 처리 범위

새 OCR과 AI 업스케일링은 포함하지 않습니다. 기존 텍스트·벡터·숨은 OCR 층을 유지하면서 **이미지 객체를 같은 PDF 참조 안에서 교체**합니다. 페이지 전체를 이미지로 변환하지 않습니다. Pro 결과 생성 시 PDF.js로 처리 전후의 기존 추출 텍스트를 확인하고, 확인에 실패한 결과는 제공하지 않습니다. 이 검사는 OCR 정확도나 모든 PDF 기능의 보존을 보증하지 않습니다.

- 지원: 명시적인 DeviceRGB/DeviceGray, 8비트 JPEG, 단순 raw/Flate 이미지. 지원되는 PNG/TIFF predictor 처리 포함.
- 원본 유지: 투명도·마스크, CMYK/ICC/Indexed 색상, JBIG2/CCITT 등 다른 압축, 1비트 이미지, 사용자 지정 Decode, 안전하게 해석할 수 없는 JPEG 메타데이터.
- 메모리 제한: 16MP 또는 긴 변 16,384px를 초과하는 원본 이미지 등은 건너뛰고 보고합니다. 큰 문서는 기기 메모리에 따라 처리 시간이 길어질 수 있습니다.
- 최신 브라우저의 Canvas와 DecompressionStream을 사용합니다. DecompressionStream이 없는 브라우저에서는 해당 Flate 이미지를 보존하고 보고합니다.
- 압축만 적용할 때 이미지 데이터가 더 커지면 원본을 유지합니다. 보정·워터마크·페이지 설정은 최종 용량을 늘릴 수 있습니다.
- 재단은 CropBox를 바꾸는 **표시 영역 조절**이며 민감정보 영구 삭제가 아닙니다. A4 맞춤은 벡터·텍스트를 비례 이동·확대축소합니다.
- 하나의 원본 전체 페이지가 원래 순서대로 남아 있으면 원본 문서 객체를 수정하여 양식·책갈피 등 문서 전체 설정을 유지합니다. 여러 문서를 합치거나 페이지를 삭제·재배열하면 기존 페이지 복사 경로를 사용하므로 양식·책갈피 등 문서 전체 설정은 보존 대상이 아닙니다. 전자서명 유효성 보존은 지원하지 않습니다.

실제 ABBYY 출력물 전체에 대한 호환성 검증은 별도입니다. 합성 숨은 영문·한글 OCR, 공유 이미지, 페이지 회전·재단·A4 변환을 회귀 테스트로 확인합니다.

## 개발과 검증

Node.js 22 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
node scripts/build.mjs
node --test tests/*.test.cjs
```

`src/editor.js`는 Basic 편집 로직, `src/pro-engine.js`는 이미지 처리, `src/pro-document.js`는 페이지 규격·번호·워터마크, `src/pro-ui.js`는 Pro 상호작용입니다. 빌드는 이 파일들과 패널·스타일을 `index.html`에 인라인합니다. 기존 PDF 라이브러리·폰트·CMap 및 라이선스는 그대로 포함됩니다.

`index.html`을 더블클릭하거나 정적 서버에서 열어 확인합니다. `src/`를 수정했다면 반드시 빌드를 다시 실행하세요.

## 기능

| | |
|---|---|
| **페이지 편집** | 여러 PDF를 합쳐서 순서 변경 · 회전 · 삭제 |
| **사진 삽입** | JPG·PNG·WEBP·GIF 등을 새 페이지로 추가하거나, 페이지 위에 직접 붙이기 |
| **영역 강조** | 사각형 · 타원 · 클라우드 마크를 그려 저장 시 PDF에 벡터로 인쇄 |
| **모바일 지원** | 페이지/미리보기 전환, 길게 눌러 순서 변경, 핀치 확대, 하단 액션바 |
| **화면 테마** | 시스템 설정 · 밝게 · 어둡게 |

## 사용

GitHub Pages에 배포되어 있다면 주소를 열기만 하면 됩니다.
내려받아 `index.html`을 더블클릭해도 똑같이 동작합니다 — 서버도, 설치도 필요 없습니다.

### 단축키

| 키 | 동작 |
|---|---|
| `Shift` + 클릭 | 범위 선택 |
| `Ctrl` / `⌘` + 클릭 | 개별 선택 토글 |
| `Ctrl` / `⌘` + `A` | 전체 선택 |
| `Ctrl` / `⌘` + `S` | PDF로 저장 |
| `Ctrl` / `⌘` + 휠 | 보드 열 수 조절 / 미리보기 확대·축소 |
| `Del` | 선택 항목 삭제 |
| `Esc` | 그리기 도구 해제 |

## 디자인 노트

- 청회색 작업 영역과 파란 강조색, 둥근 패널로 문서와 조작 영역을 구분합니다.
- Basic은 페이지 정리와 미리보기에 집중하고, Pro는 같은 문서 옆에 상세 설정을 펼칩니다.
- 모바일 Pro 설정은 별도 화면으로 전환하며, 편집 화면으로 돌아와 페이지를 선택할 수 있습니다.
- 기존 SVG 아이콘과 시스템 글꼴을 사용하고 밝은 테마·어두운 테마·동작 줄이기 설정을 지원합니다.
